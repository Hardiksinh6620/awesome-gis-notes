# Vector vs Raster

**Vector** — discrete features: points, lines, polygons. Great for boundaries,
roads, parcels. Attribute tables.

**Raster** — continuous grid of cells. Great for elevation, imagery, temperature.

| | Vector | Raster |
|--|--------|--------|
| Storage | coords + attributes | pixel values |
| Formats | GeoJSON, SHP, GPKG | GeoTIFF, COG |
| Best for | discrete features | continuous fields |
